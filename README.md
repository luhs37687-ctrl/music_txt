# music_txt

手机 App 在线曲谱下载用的曲谱文件仓库。

## 曲谱格式

```
音高Hz,时长ms;音高Hz,时长ms;...
```

- `;` 分隔不同音符
- `,` 分隔 **音高(Hz)** 和 **时长(ms)**
- 蓝牙发送时会加前缀 `SONG,` 和结尾 `\n`
